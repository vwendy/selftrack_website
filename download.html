Before you install

  • Read how it works and what it records.
  • Follow the install guide. Android will ask you to allow installs from your browser because the app is not in the Play Store.
  • Only install SelfTrack from this website, so you know the file has not been changed.

Check the file (optional)

To confirm the file was not altered, compare its SHA-256 checksum with this one. In Windows PowerShell: Get-FileHash SelfTrack.apk.

Release notes

1.0: first public release. Records app use, screen events, light and step sensors and mood check-ins on your phone. Optional tap, scroll and typing timing through Android Accessibility. Charts and plain-language explanations of your own data. Export and delete-all controls. See all versions on the Releases page.

SelfTrack is a self-reflection tool. It is not medical advice. We never receive your data.
