# SelfTrack website

Public website and downloads for **SelfTrack**, an Android app that relates how you use your phone to a short mood check-in. Your data stays on your phone; the developers never receive it.

- Site: https://vwendy.github.io/selftrack_website/
- Download: see the Releases page of this repository, or the Download page of the site.

The site is plain HTML and CSS with no scripts, cookies or trackers.
